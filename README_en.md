# EMSOptimizer
![logo](./logo.svg)
EMSOptimizer is a mathematical optimization library specialized for the design of electrical equipment.  
This repository contains the open-source code portion of EMSOptimizer (EMSOptFree).  

## Installation Guide
*Python 3.11.x environment and pip package manager is required

1. Download the latest version of the EMSOptimizer zip (or tar.gz) file and the accompanying whl file from "Releases" of this repository.

2. Unzip the downloaded zip (or tar.gz) file to any location you prefer in your PC.

3. Via command line tool, install the downloaded whl file using `pip install`.
```sh
pip install emsopt_engine-(version)-(environment)-(os).whl
```
* it will take a few minutes to install its dependencies.

4. To enable the shape optimization function, install the required modules according to the respective procedures.  
*For required modules and others, please refer to [the installation guide on the documentation site](https://emsolution-ssil.github.io/EMSOptimizerDoc/).

### For developers
Instead of downloading and unzipping our zip (or tar.gz) source folder, you can clone this repository to your PC.
